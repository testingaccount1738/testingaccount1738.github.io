# Star Swarm

A small Galaga-inspired browser shooter built with plain HTML, CSS, and JavaScript.

## Play it

1. Open `/Users/nathanielboen/Documents/Playground/placeholder/galaga-browser/index.html` in a browser.
2. If your browser blocks local file behavior, run a simple local server from this folder:

```bash
cd /Users/nathanielboen/Documents/Playground/placeholder/galaga-browser
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Controls

- Move: Left / Right arrows or `A` / `D`
- Shoot: Space
- Start / Restart: Enter
